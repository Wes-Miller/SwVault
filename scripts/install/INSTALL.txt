SwVault - install

1. Close SOLIDWORKS.
2. Double-click "Install SwVault.cmd" and approve the administrator prompt.
3. A SwVault window asks for your user name and password (from your team admin).
   Sign in. Your team's files start downloading to the vault folder (e.g. C:\SWVault\FSAE);
   the SwVault tray icon tells you when they're all there.
4. Open SOLIDWORKS. Use the SwVault tab and task pane. See the user guide for the basics.

Closed the sign-in window? Double-click the SwVault tray icon, or use Connect vault... in the
SwVault task pane in SOLIDWORKS.

Package without a team (no bin\team.json)? After installing, click the SwVault tray icon >
Vaults... and enter the repository URL, your user name and an access token from your admin.

Problems? Run "swvault doctor" in a terminal and send the output to your admin.
To remove: run uninstall.ps1 (in C:\Program Files\SwVault).
